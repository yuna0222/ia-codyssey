# Emergency Storage 암호 해독기

암호가 걸린 `emergency_storage_key.zip` 파일을 자동으로 풀어주는 프로그램입니다.

---

## 탐색 전략

무조건 22억 가지를 전부 시도하는 대신,  
가능성이 높은 후보를 먼저 시도하고 마지막에 전체를 탐색합니다.

1. **스토리 기반 우선순위 단어 탐색** — `mars`, `oxygen`, `coffee` 등 의미 있는 키워드를 먼저 시도
2. **숫자 6자리 암호 우선 탐색** — 가능성이 높은 작은 탐색 범위를 먼저 검사
3. **영단어 + 숫자 조합 우선 탐색** — `mars01`, `base99` 등의 패턴 우선 시도
4. **멀티프로세싱 병렬 처리** — CPU 코어별로 탐색 범위를 분산하여 병렬 수행
5. **최종 전체 브루트포스 탐색** — 우선순위 탐색 실패 시 전체 경우의 수 탐색

---

## 파일 구성

```
프로젝트 폴더/
├── door_hacking.py              # 메인 프로그램
├── emergency_storage_key.zip    # 암호 해제 대상 ZIP 파일
└── password.txt                 # 암호 발견 시 자동 생성
```

---

## 실행 방법

```bash
python door_hacking.py
```

암호를 찾으면 `password.txt` 에 자동으로 저장됩니다.

---

## 구현 내용

### 1단계 — 스토리 기반 우선순위 단어

화성 기지 스토리와 관련된 단어 중 딱 6자리인 것을 먼저 시도합니다.

```python
PRIORITY_WORDS = [
    'coffee', 'oxygen', 'storage', 'emergency',
    'mars', 'base', 'door', 'key', 'food',
    'water', 'rescue', 'space', 'human', 'life',
]
```

---

### 2단계 — 숫자 6자리

`000000` 부터 `999999` 까지 순서대로 시도합니다.  
탐색 범위가 100만 가지로 작아서 빠르게 끝납니다.

---

### 3단계 — 영단어 + 숫자 조합

단어 앞뒤에 숫자를 붙인 조합을 시도합니다.

```
mars → mars00, mars01 ... mars99
mars → 00mars, 01mars ... 99mars
```

---

### 1~3단계 공통 — ZIP 파일 재사용

ZIP 파일을 **한 번만 열어두고** 모든 후보를 시도합니다.  
매번 파일을 열고 닫으면 오버헤드가 발생하기 때문입니다.

---

### 4단계 — 멀티프로세싱 병렬 처리 + 전체 브루트포스

1~3단계에서 못 찾으면 전체 22억 가지를 탐색합니다.  
CPU 코어 수만큼 프로세스를 나눠서 각자 담당 구간을 병렬로 탐색합니다.

```
전체 22억 가지
├── Process 1: 0 ~ 2.4억
├── Process 2: 2.4억 ~ 4.8억
├── ...
└── Process N: ... ~ 22억
```

한 프로세스가 암호를 찾으면 `found_event` 로 나머지 프로세스에 즉시 종료 신호를 보냅니다.  
각 프로세스도 ZIP 파일을 한 번만 열고 재사용합니다.

---

## 주요 함수

| 함수 | 역할 |
|------|------|
| `unlock_zip()` | 전체 흐름 제어 — 1~3단계 → 4단계 순으로 실행 |
| `make_priority_candidates()` | 우선순위 후보 목록 생성 |
| `try_priority_passwords()` | ZIP 한 번 열고 후보 순차 시도 |
| `unlock_zip_bruteforce()` | 멀티프로세스 전체 탐색 |
| `worker()` | 각 프로세스가 담당 구간을 탐색 |
| `try_password()` | 열린 ZIP 객체로 암호 하나를 검증 |
| `number_to_password()` | 숫자를 암호 문자열로 변환 |
| `find_smallest_file()` | ZIP 안에서 가장 작은 파일 선택 (검증 속도 최적화) |
| `save_password()` | 찾은 암호를 `password.txt` 에 저장 |
| `check_zip_file()` | ZIP 파일 유효성 확인 및 검증 대상 파일 선택 |

## 제약 조건

- 암호 길이: 6자리
- 암호 구성: 숫자(`0-9`) + 소문자 알파벳(`a-z`)
- 특수 문자 없음

## 배운 점

- ZIP 파일을 매번 열고 닫는 대신 한 번만 열고 재사용하면 오버헤드를 크게 줄일 수 있다.
- 멀티프로세싱으로 CPU 코어 수만큼 병렬 탐색하면 탐색 속도가 코어 수에 비례해서 빨라진다.
- 무작정 전체를 탐색하는 것보다 의미 있는 후보를 먼저 시도하는 전략이 실제로 유효하다.
- `multiprocessing.Event` 로 프로세스 간 종료 신호를 공유하면 한 프로세스가 성공했을 때 나머지를 즉시 멈출 수 있다.
