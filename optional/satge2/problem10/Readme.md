# 🔴 화성 기지 CCTV 뷰어 + 사람 탐지

화성 기지 외부에 설치된 CCTV 사진을 보고,  
AI가 자동으로 사진 속 사람을 찾아주는 프로그램입니다.

---

## 📌 이 프로그램이 하는 일

**기능 1 — CCTV 사진 뷰어**
- cctv.zip 파일을 자동으로 풀어서 사진을 불러옵니다
- 키보드 방향키로 사진을 앞뒤로 넘겨볼 수 있습니다

**기능 2 — 사람 자동 탐지**
- S 키를 누르면 AI가 사진을 처음부터 순서대로 검색합니다
- 사람이 없는 사진은 자동으로 건너뜁니다
- 사람이 발견된 사진만 화면에 표시하고, 발견된 위치에 빨간 박스를 그립니다
- 엔터키를 누르면 다음 사진으로 계속 탐색합니다
- 마지막 사진까지 다 검색하면 완료 메시지가 뜹니다

---

## 📁 필요한 파일 목록

프로그램을 실행하려면 아래 파일들이 모두 같은 폴더 안에 있어야 합니다.

```
내 폴더/
├── cctv.py           ← 이 프로그램 파일
├── cctv.zip          ← CCTV 사진들이 담긴 압축 파일
├── yolov3.weights    ← AI 모델 파일 (학습된 가중치 데이터)
├── yolov3.cfg        ← AI 모델 구조 설정 파일
└── coco.names        ← AI가 인식할 수 있는 물체 이름 목록
```

> `CCTV/` 폴더는 프로그램 실행 시 자동으로 만들어집니다. 직접 만들 필요 없습니다.  
> YOLOv3 파일 3개는 없을 경우 프로그램이 자동으로 다운로드를 제안합니다.

---

## 🛠️ 실행 전 준비

### 1단계 — opencv 설치

터미널(맥: Terminal, 윈도우: 명령 프롬프트)을 열고 아래 명령어를 입력합니다.

```bash
pip install opencv-python
```

> **opencv가 뭔가요?**  
> 이미지를 읽고 처리하는 기능을 모아놓은 도구입니다.  
> 이 프로그램에서는 사진을 읽고, AI로 사람을 찾는 데 사용합니다.

---

### 2단계 — AI 모델 파일 준비

사람을 인식하려면 YOLOv3 모델 파일 3개가 필요합니다.

**방법 A — 프로그램이 자동으로 다운로드 (권장)**

파일이 없는 상태에서 S 키를 누르면 아래 팝업이 뜹니다.

```
YOLOv3 파일 없음
YOLOv3 모델 파일이 없습니다.
자동으로 다운로드할까요? (약 236MB, 시간이 걸릴 수 있습니다)
[예]  [아니오]
```

`예` 를 누르면 Python 내장 모듈(`urllib`)로 자동 다운로드가 시작됩니다.  
터미널에 진행 상황이 출력되며, 완료 후 탐지가 자동으로 시작됩니다.

**방법 B — 직접 다운로드**

터미널에서 아래 명령어를 순서대로 입력합니다.

```bash
curl -L https://pjreddie.com/media/files/yolov3.weights -o yolov3.weights
curl -L https://raw.githubusercontent.com/pjreddie/darknet/master/cfg/yolov3.cfg -o yolov3.cfg
curl -L https://raw.githubusercontent.com/pjreddie/darknet/master/data/coco.names -o coco.names
```

| 파일 | 크기 | 역할 |
|------|------|------|
| `yolov3.weights` | 약 236MB | AI가 학습한 결과물. 사람을 알아보는 핵심 데이터 |
| `yolov3.cfg` | 약 8KB | AI 모델의 구조를 설명하는 설정 파일 |
| `coco.names` | 약 1KB | AI가 인식할 수 있는 물체 이름 80가지 목록 |

> `yolov3.weights` 파일이 약 236MB라 다운로드 시간이 걸릴 수 있습니다.

---

### 3단계 — 실행

```bash
python cctv.py
```

## 🖥️ 사용 방법

### 기본 뷰어 화면

프로그램을 실행하면 CCTV 사진 뷰어 창이 열립니다.

| 조작 | 동작 |
|------|------|
| `→` 오른쪽 방향키 | 다음 사진으로 넘김 |
| `←` 왼쪽 방향키 | 이전 사진으로 돌아감 |
| `S` 키 또는 🔍 버튼 클릭 | 사람 탐지 시작 |

---

### 사람 탐지 화면

`S` 키를 누르면 별도 창이 열리고 탐지가 자동으로 시작됩니다.

**탐지 흐름**

```
첫 번째 사진 분석
    ↓
사람 없음 → 자동으로 다음 사진으로 넘어감
    ↓
사람 발견 → 화면에 표시 (빨간 박스) + 멈춤
    ↓
Enter 키 입력
    ↓
다음 사진부터 계속 탐색
    ↓
마지막 사진까지 완료 → "모든 사진 탐지 완료!" 메시지
```

| 조작 | 동작 |
|------|------|
| 자동 진행 | 사람 없는 사진은 알아서 건너뜀 |
| `Enter` | 사람 발견 후 다음 사진으로 계속 탐색 |

## 🏗️ 코드 구조 설명

이 프로그램은 4개의 클래스로 나뉘어 있습니다.  
각 클래스는 하나의 역할만 담당하도록 설계했습니다.

---

### `MasImageHelper` — 사진 관리 담당

사진 파일 목록을 불러오고, 압축 파일을 푸는 역할입니다.  
화면 표시나 탐지와는 완전히 분리되어 있어서, 다른 프로젝트에서도 그대로 가져다 쓸 수 있습니다.

**주요 동작**

- 프로그램 시작 시 `CCTV` 폴더가 없으면 `cctv.zip` 을 자동으로 압축 해제
- ZIP 파일 안에 폴더 구조가 없어도 (파일만 바로 들어있어도) 자동으로 `CCTV/` 폴더를 만들어서 정리
- `.jpg` `.jpeg` `.png` `.bmp` `.gif` 형식만 인식하고 나머지 파일은 무시
- 파일 이름 기준으로 정렬해서 순서대로 표시

**상수 목록**

| 상수 | 값 | 의미 |
|------|----|------|
| `EXTENSIONS` | `.jpg` `.jpeg` `.png` `.bmp` `.gif` | 인식할 이미지 형식 |
| `DEFAULT_FOLDER` | `'CCTV'` | 사진이 저장될 폴더 이름 |
| `DEFAULT_ZIP` | `'cctv.zip'` | 압축 파일 이름 |

**메서드 목록**

| 메서드 | 하는 일 |
|--------|---------|
| `__init__()` | 폴더 확인 → 없으면 ZIP 해제 → 파일 목록 로드 |
| `_extract()` | ZIP 파일 압축 해제 (내부에서만 사용) |
| `move(step)` | `+1` 이면 다음, `-1` 이면 이전 사진으로 이동 (순환) |
| `has_next()` | 마지막 사진이 아니면 `True` 반환 |
| `current_image()` | 현재 사진을 이미지 객체로 반환 |
| `current_path()` | 현재 사진의 파일 경로를 반환 |
| `status()` | `"cctv-1.jpg (1/4)"` 형식의 상태 문자열 반환 |

---

### `PersonDetector` — 사람 탐지 담당

OpenCV 내장 딥러닝 모듈(`cv2.dnn`)로 YOLOv3 모델을 실행해 사람을 찾습니다.  
TensorFlow, PyTorch 같은 별도 AI 라이브러리 없이 `opencv-python` 하나로 동작합니다.

**주요 동작**

1. 이미지를 608×608 크기로 변환해서 YOLO 모델에 입력
2. 모델이 이미지 전체를 한 번에 분석해서 사람 위치와 신뢰도를 출력
3. 신뢰도가 15% 미만인 결과는 제외
4. 같은 사람을 여러 번 감지한 경우 가장 신뢰도 높은 박스 하나만 남김 (NMS)
5. 사람 위치에 빨간 사각형과 신뢰도 퍼센트를 이미지에 직접 그려서 반환

**상수 목록**

| 상수 | 값 | 의미 |
|------|----|------|
| `WEIGHTS` | `'yolov3.weights'` | AI 모델 가중치 파일 경로 |
| `CONFIG` | `'yolov3.cfg'` | AI 모델 구조 파일 경로 |
| `NAMES` | `'coco.names'` | 클래스 이름 목록 파일 경로 |
| `URLS` | 각 파일의 다운로드 URL | 파일 없을 때 자동 다운로드에 사용 |
| `CONFIDENCE_THRESHOLD` | `0.15` | 신뢰도 임계값. 낮을수록 더 많이 감지 (오탐도 증가) |
| `NMS_THRESHOLD` | `0.3` | 중복 박스 제거 기준. 낮을수록 박스가 적게 남음 |
| `INPUT_SIZE` | `(608, 608)` | YOLO 입력 이미지 크기. 클수록 작은 물체도 잘 감지 |

**메서드 목록**

| 메서드 | 하는 일 |
|--------|---------|
| `__init__()` | 모델 파일 존재 확인 → YOLOv3 모델 로드 → 클래스 목록 로드 |
| `download_models()` | 모델 파일 3개를 `urllib` 로 자동 다운로드 (성공: True, 실패: False) |
| `detect(image_path)` | 이미지에서 사람 탐지 → 박스 그린 이미지와 감지 수 반환 |

**메서드 목록**

### `DetectionViewer` — 사람 탐지 화면 담당 (문제 10)

`S` 키를 누르면 열리는 별도 탐지 창입니다.  
`MasImageHelper` 와 `PersonDetector` 를 받아서 사진을 순서대로 탐색합니다.

**탐지 로직 (`_search_next`)**

```
현재 사진 탐지
├── 탐지 성공 (사람 있음) → 화면 표시 후 Enter 대기
├── 탐지 실패 (사람 없음) → 자동으로 다음 사진으로 이동
├── 이미지 오류 (손상된 파일) → 건너뛰고 계속 진행
└── 마지막 사진까지 완료 → 완료 메시지 표시, Enter 바인딩 해제
```

**메서드 목록**

| 메서드 | 하는 일 |
|--------|---------|
| `__init__()` | UI 구성 → 첫 번째 사진부터 탐지 시작 |
| `_build_ui()` | 창·캔버스·레이블 생성 및 Enter 키 바인딩 |
| `_search_next()` | 사람 발견될 때까지 사진을 순차 탐색하는 핵심 로직 |
| `_on_enter()` | Enter 키 입력 시 다음 사진부터 탐색 재개 |
| `_done()` | 완료 메시지 표시 및 Enter 바인딩 해제 |
| `_show()` | 탐지 결과 이미지를 캔버스에 표시 |

## 🤖 AI 사람 탐지 원리 (YOLO)

**YOLO** 는 "You Only Look Once" 의 약자로,  
이미지를 딱 한 번만 훑어보고 물체를 찾아내는 AI 모델입니다.

### 일반적인 방법 vs YOLO

| 구분 | 일반적인 방법 | YOLO |
|------|------------|------|
| 방식 | 이미지를 수천 개 조각으로 잘라서 각각 분석 | 이미지 전체를 한 번에 분석 |
| 속도 | 느림 | 빠름 |
| 사용처 | 과거 방식 | 현재 널리 사용 |

### YOLO 동작 순서

```
① 이미지를 격자로 나눔
   (13×13칸, 26×26칸, 52×52칸 — 크기별로 3번 분석)
        ↓
② 각 칸마다 동시에 예측
   - 이 칸에 물체가 있나?
   - 있다면 박스 위치와 크기는?
   - 그게 뭐야? (person, car, dog 등 80가지 중 하나)
        ↓
③ 신뢰도가 15% 미만인 결과 제거
        ↓
④ NMS — 같은 사람을 여러 칸이 동시에 잡으면
         신뢰도 가장 높은 박스 하나만 남김
        ↓
⑤ 남은 박스를 이미지에 빨간 사각형으로 표시
```

### 누운 사람 인식률이 낮은 이유

YOLO 학습에 사용된 사진 대부분이 **서 있거나 앉아있는 사람** 위주입니다.  
이 프로그램의 CCTV 사진처럼 **누워있거나 우주복을 입은 경우**는 학습 데이터가 적어서 인식률이 떨어질 수 있습니다.

`CONFIDENCE_THRESHOLD` 값을 더 낮추면 더 많이 감지되지만, 사람이 아닌 것도 사람으로 잘못 인식하는 경우가 늘어납니다.

## ⚠️ 오류 상황별 대처

| 상황 | 프로그램 반응 |
|------|-------------|
| `CCTV` 폴더도 없고 `cctv.zip` 도 없음 | 팝업 오류 메시지 표시 후 종료 |
| ZIP 안에 이미지 파일이 하나도 없음 | 팝업 오류 메시지 표시 후 종료 |
| ZIP 안에 폴더 구조 없이 파일만 있음 | `CCTV/` 폴더 자동 생성 후 해제 |
| 사진 파일이 손상되어 열리지 않음 | 해당 파일 건너뛰고 다음 파일 계속 진행 |
| YOLOv3 모델 파일 없음 | 팝업으로 다운로드 여부 확인 후 자동 다운로드 |
| 다운로드 실패 (인터넷 연결 없음 등) | 팝업 오류 메시지 표시 후 탐지 취소 |
